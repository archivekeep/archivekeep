ArchiveKeep helps you preserve your personal files by maintaining identical copies across multiple storage locations — without risking corruption or data loss during synchronization.

Once a file is archived, it stays unchanged. ArchiveKeep never overwrites existing copies with modifications or corrupted data, ensuring your archives remain intact over time.

Features:
<ul>
    <li>Plain files — no proprietary format, readable with any application.</li>
    <li>Incremental synchronization — replicates new files or moves when storages become available, working fully offline.</li>
    <li>SHA-256 file fingerprinting — fast verification that catches silent bit-rot before it spreads.</li>
    <li>Multi-platform — available on Linux desktop and Android.</li>
    <li>No vendor lock-in — you control where your files live.</li>
</ul>

Optional cloud storages (not required):
<ul>
    <li>Google Drive — convenient, familiar, widely available.</li>
    <li>S3-compatible APIs — choose any vendor that supports the S3 protocol.</li>
</ul>

Cloud storage is entirely optional. The app works fully offline with local storage only — no Google accounts, no proprietary services, and no internet connection required. Google Drive and S3 are available as optional additions if you want them.

<em>ArchiveKeep is in active development</em> and improving with each release. Feedback and bug reports are welcome.
